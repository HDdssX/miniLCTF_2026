# 博丽神社的御神签

- 类型：Web
- 本地端口：`5000`

## 题面

最近来博丽神社抽签的人很多，香火钱却依旧寥寥无几。博丽灵梦为了节省人工成本，接受了“河童重工”的最新技术提案，上线了一套全自动的云端抽签系统。这套系统不仅能自动吐出御神签，还配备了“新一代河童数据库”和后台管理界面，方便灵梦足不出户就能修改签文。

然而，河童们的代码一如既往地存在“特性”。系统刚一上线，路过的雾雨魔理沙似乎就发现了一些有趣的入口。

提示：Flag 位于 `/tmp` 文件夹下。

## 启动方式

```bash
docker compose up --build
```

启动后访问：

```text
http://127.0.0.1:5000
```

## 目录说明

- `app.py`：Flask 页面与 `/rest/v1/*` 代理
- `build_assets/`：数据库初始化、PostgREST 配置、启动脚本
- `templates/`、`static/`：前后台页面资源
